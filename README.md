# kondate-repo

家族用献立ページのリポジトリです。

## 概要

- 夕食の献立を家族が閲覧するための静的ページです。「今日の献立」と「今月の献立」（カレンダー）から、各料理のレシピノートを見られます
- GitHub Pages で公開しています: https://marmia.github.io/kondate-repo/
- ページ本体は `index.html`（単一ファイル）です。献立データはファイル内のデータをもとに、JavaScript で表示を生成します

## 更新について

- 献立の提案・修正に合わせて、献立管理エージェント（栄養管理士リサ）がこのリポジトリを更新します
- 献立データの正本は献立作成アプリ側にあり、このリポジトリは家族向けの公開用です
